# .claude/skills — 全セッション共有のスキル置き場

ここに置いた skill は **git 管理され、このリポジトリを clone/open した全ての環境で自動的に使える**。

## なぜここに置くか

このプロジェクト向けの専用スキル（`carelink-commander` / `perfect-code-carelink` /
`sync-claude-md-carelink`）は元々 `soel` リポジトリ（複数プロジェクトを横断する司令塔
リポジトリ）に集約されていたが、**CareLink 自身を開いたセッションからは見えなかった**
（Claude Code はセッションが開いているリポジトリの `.claude/skills/` しか自動で読み込まず、
他リポジトリを横断参照する仕組みが無いため）。このリポジトリへ移設することで、
GitHub 連携・Claude Code on the web・Cowork など、CareLink を直接開くあらゆるセッションで
自動的に使えるようにした（2026年8月9日）。

`.gitignore` の書き方に注意。`.claude/` とディレクトリ指定すると git が中へ降りず、
配下の `!` 例外が効かない（git の仕様）。そのため `.claude/*` + `!.claude/skills/` にしてある。

## 置いてよいもの / いけないもの

| | |
|---|---|
| ⭕ 置く | このプロジェクトで完成済み・共有したいスキル |
| ❌ 置かない | 個人の実験用・未完成のもの（**全セッションの挙動が変わる**） |
| ❌ 置かない | トークン・顧客データ等の秘密情報（`.env` と同じ扱い） |

⚠️ ここに置いたスキルは**並行して動いている他のセッションにも即座に効く**。
追加・変更は他セッションの作業を壊さないか確認してから行うこと。

## soel との関係

ここに置く3スキルは **soel からこのリポジトリへコピーした派生**。元の編集履歴・雛形は
`soel` 側にある。将来 `soel` 側を更新した場合、このリポジトリへの反映は手動で行う必要がある
（自動同期の仕組みは無い）。差分が出た場合は `soel` 側を正とする。
