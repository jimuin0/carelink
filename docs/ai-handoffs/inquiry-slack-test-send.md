## Claude経由のCodex判定（2026-11-27・対象 ea281e87b6689bfed857ca671454fdecd87c8c32）

### 指摘

**SLACK-TEST-01（重要度・中、基準1）**  
該当箇所は `src/app/api/admin/inquiries/slack-test/route.ts:30–33` と `src/lib/with-route.ts:123–151` です。

- **期待値**　CSRF 検証を通過した未ログイン利用者には 401、非管理者には 403 を返し、運営管理者のテスト送信枠は消費しない。
- **実際値**　同じ IP から未ログイン利用者または非管理者が10分以内に有効な送信リクエストを3回行うと、その後の運営管理者のリクエストは認証前に 429 になります。同じ IP の未ログイン・非管理者への応答も 429 になります。
- **根拠**　`withRoute` は CSRF 検証後、認証と管理者照会より先に IP 単位のカウンターを更新します。既存のルートテストはレート制限の結果をモックしており、拒否されたリクエストによる枠の消費は検査していません。
