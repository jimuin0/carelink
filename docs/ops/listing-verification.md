# 店舗確認の運用手順

新規店舗は、店舗確認書類と申請者の管理権限を運営が確認してから、店舗側が公開する。書類の提出だけでは確認完了にならない。既存の公開店舗は公開を維持し、順次確認する。

## 申込者の操作

1. 店舗ごとに掲載を申し込み、申込時のメールアドレスを確認した店舗アカウントで申込を引き継ぐ。
2. 管理画面の「施設設定」で対象店舗を選び、「店舗確認書類の提出」から書類の種類とファイルを選んで提出する。PDF・JPEG・PNG、1ファイル10 MiBまで。
3. 「書類を受け付けました」と表示されたことを確認する。受付結果が不明な場合は、同じ書類のまま「受付状況を再確認」を使う。
4. 運営の確認後、店舗名・所在地・曜日別営業時間などの公開条件を整え、店舗側で公開する。ネット予約の設定は無料掲載に必須ではない。

書類は必要な部分を残し、金額・口座番号・マイナンバーなど不要な情報を隠してもらう。他サイトの掲載URLは補助資料であり、書類と管理権限の確認に代わるものではない。

## 運営の確認

1. 運営管理者で「施設登録管理」を開き、「提出書類の確認」で一覧を読み込む。書類の準備だけでは表示されず、実際の保存を確認した書類が対象になる。必要に応じて次の範囲も確認する。対象の申込または「既存店舗の確認」で店舗を探すこともできる。
2. 「店舗確認書類を読み込む」を押し、店舗名・所在地と提出者を確認する。「書類を開く」で内容を読み、確認に使った書類を選択する。
   書類の種類が一覧に出ていても、アップロード途中の可能性がある。実際に書類を開いて内容を確認できるまでは、提出・確認完了と扱わない。
3. 書類と店舗情報を照合する。原則1点から確認できるが、店舗名・所在地・運営者の関係が読み取れない場合は、必要に応じて追加資料を求める。書類の提出だけで管理権限があるとは判断しない。
4. 提出者が店舗情報を管理できる権限を、書類や独立した連絡先などで別に確認する。確認できない場合はチェックせず、確認が取れるまで記録しない。連絡方法の希望にも従う。
5. 両方を確認できたときだけ「書類と店舗情報を照合しました」「申請者の管理権限を確認しました」にチェックし、「確認を記録する」を押す。店舗は自動公開されず、店舗側が公開する。
6. 結果が不明な場合は画面の案内に従って情報を読み直し、確認記録を確かめる。確認できないまま承認済みと扱わない。

## 運用上の注意

- 確認書類は非公開で保存される。書類の真偽や管理権限は自動判定されない。
- 書類提出の自動通知は、この手順を確認した時点では見当たらない。施設登録管理で一覧を読み込んで確認する必要がある。
- 確認後の店舗側への自動通知は、この手順では確認していない。連絡が必要な場合は送信状況と本人の希望を確認する。
- 店舗名や所在地を変更すると確認のやり直しが必要な場合がある。画面の案内に従う。
